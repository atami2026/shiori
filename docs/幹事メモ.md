## 1. ホテル写真の掲載許可の問い合わせ

しおり内でホテルの公式写真（客室・温泉・館内施設）を表示するには、ホテルの許可が必要です。
許可が取れるまでは、写真の代わりに「公式ページで写真を見る」ボタンを表示しています。

### 問い合わせ先
- 熱海ニューフジヤホテル（伊東園ホテルズ）
- 電話：0570-022-780
  - ※ 日本旅行など複数の予約サイトに載っている番号です。ホテル公式サイトでは未確認です。
- 公式サイトの「お問い合わせ」ページがあれば、そちらでも可

### 電話で聞く内容（読み上げ用）
> 10月23日から1泊で、アネックス館の和室12畳を3部屋予約している団体の幹事です。
> 参加者18名だけに配る旅のしおり（スマホで見るWebページ）を作っています。
> その中で、貴館の公式サイトに載っている客室・温泉・館内施設の写真を、出典を書いたうえで表示してもよいでしょうか。
> - 表示したい写真：アネックス館 和室12畳の客室写真、大浴場・展望露天風呂・家康の湯、カラオケ・卓球・ゲームコーナー、朝食
> - 使い方：公式サイトの画像をそのまま表示し、写真ごとに「出典：熱海ニューフジヤホテル公式サイト」とリンクを付けます。加工はしません。
> - 公開範囲：検索エンジンには載せず、参加者にLINEでURLを送るだけです。旅行後は公開を止めます。
>
> もし難しければ、公式ページへのリンクだけにします。

### 聞いておくとよいこと
- 写真の表示はOKか（条件があれば、その条件）
- 朝食会場の場所
- ロビーで18名が集合しやすい場所
- 本館と別館（アネックス）の行き来のしかた
- 当日の温泉・館内施設の休止予定

### 許可が取れたら
`data/trip.js` の `photoMode: "link"` を `photoMode: "embed"` に変えるだけで、写真がしおりに表示されます（タップで拡大・左右で切替）。
写真が読み込めない場合は、自動で公式ページへのリンクに切り替わります。

## 2. 公開（GitHub Pages）の手順

GitHub Pages（ギットハブ・ページズ＝GitHubの無料公開機能）で、URLを作ります。

1. GitHub で `daichan1030/shiori` を開く
2. **Settings（設定）** → 左の **Pages**
3. 「Build and deployment」の Source を **Deploy from a branch** にする
4. Branch を **`ccr-49463243-48bgo7`**、フォルダを **`/ (root)`** にして **Save**
5. 1〜2分待つと、`https://daichan1030.github.io/shiori/` で見られます

### 注意
- このリポジトリは公開（public）なので、ページの中身もソースも誰でも見られます。参加者の名前・部屋割り・個人の連絡先は書かないでください。
- 検索エンジンには載らない設定（noindex）にしてあります。
- リポジトリを非公開（private）にすると、無料プランでは GitHub Pages が使えなくなります（有料プランが必要）。
- 旅行が終わったら、同じ画面で Pages を止められます（Source を「None」にする等）。
