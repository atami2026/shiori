# 熱海旅行2026 しおり（スマホ向けWebアプリ）

参加者18名にURLで共有する旅のしおりです。ビルド不要の静的サイト（HTML / CSS / JavaScript）です。

## ファイル
- `index.html` … 入口
- `data/trip.js` … **幹事が編集する設定データ**（日付・時刻・案内文・施設時間・リンク・写真）
- `assets/style.css` … デザイン
- `assets/app.js` … 画面と動き（予定／交通／ホテル／施設／宴会／案内）

## 見かた（手元で確認）
```
python3 -m http.server 8765
```
ブラウザで http://localhost:8765/ を開く。`index.html` を直接ダブルクリックしても動きます。

## 編集ルール
- 料金・金額は書かない（参加者向け画面に一切出さない）
- 参加者の氏名・部屋割り・個人の連絡先は書かない
- 未確定の内容は status を「予定」「仮案」「第1候補」「要確認」にする

## 写真について
`data/trip.js` の `photoMode` で切り替えます。
- `"link"` … 写真は直接表示せず、公式ページの該当写真へのリンクカードを表示
- `"embed"`（現在の設定）… 公式の画像URLを直接表示（タップで拡大・左右切替）。読み込めない写真は自動で公式ページへのリンクに差し替え

写真の表示をやめたいときは `"link"` に戻してください。
URLの末尾へ `?photos=off` を付けると一時的にリンク表示、`?photos=on` で写真表示になります（例: `http://localhost:8765/?photos=on#/hotel`）。

## 幹事向け
写真の掲載許可の問い合わせ方、公開手順、LINEの文面は `docs/幹事メモ.md` にまとめています。

## LINE共有の準備
- `og:image` は GitHub Pages の公開URL（`https://daichan1030.github.io/shiori/`）で設定済みです。別の場所で公開する場合は書き換えてください。
- `sw.js` により、一度開いたあとは電波が弱くても前回の内容を表示できます（更新はネット優先で反映）。
- `robots` は `noindex, nofollow`（検索に載せない）にしています。

## テスト
```
python3 -m http.server 8765 &
node tests/e2e.js            # playwright が必要
```
